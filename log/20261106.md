# Pattern matching improvements

## Work completed
* Now supports nested pattern matching, e.g. when before `f 1 2` failed on `f = { 1 1 -> 2 | x y -> x * y }`.
* Added a couple of new tests.
* Underscores can now appear in identifier names.

## Still outstanding
* Still need a way to allow a function to be defined across multiple lines in a source file.
