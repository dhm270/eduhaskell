# Consolidation and tidying up

## Work completed
* Added a warning when we define a new function with the same name as an existing one (to highlight that it's not extending the definition of the old one).
* Debug output (e.g. printing the tree of the syntax) is now gated behind a flag.
* The string type has been removed. All strings are now sequences of characters.
* Added support for evaluating `WhereEquation`s and guarded definitions.
* Added more tests for e.g. more involved pattern matching
* Asked ChatGPT (GPT-6, Instant effort) to suggest some small test expressions I could use to investigate any lingering issues with the evaluator.

## Still outstanding
* Multi-line function definitions still don't work properly (i.e. if you were to read in a source file). Reading a source file is no different to inputting each line of the file directly into the REPL, one by one.
