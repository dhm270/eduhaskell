# Refactoring and type checking

## Work completed
* Can now evaluate `case x of { ... }`.
* Introduced `TypeEnvironment` to set up foundations for inferring types of things stored in an environment.
  * So far, only used to infer (very basic-ly) types of named variables.
* Type errors reported in the REPL.
* Type checking errors which were previously raised in the evaluator are now raised in the type checker.
* Can now evaluate arithmetic sequences which are descending.
* Lots of various refactoring / tidying up.
