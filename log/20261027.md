# Extending evaluation

## Work completed
* The REPL now has an environment which is maintained between different expressions.
* Function definitions can now be evaluated, including recursive definitions.
* Arithmetic sequences are now supported for parsing and evaluation.
* Various tests added.

## Problems encountered
* There are issues with parsing e.g. `[1..]` (specifically, the `1.` bit). `[1 ..]` works, though.
