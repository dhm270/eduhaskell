# Laziness and pattern matching

## Work completed
* Laziness works properly (I think?), e.g. `fix` now works as it should.
  * Refactored to introduce `LazyValue` to support this.
* Support for (basic) pattern matching in function definitions.
* Support for evaluating tuples.

## Still outstanding
* Pattern matching isn't complete.
* Currently the only way to define multiple possible patterns for the same function is to use the `... = { ... | ... }` syntax, i.e. we can't do multiple definitions on multiple lines.
